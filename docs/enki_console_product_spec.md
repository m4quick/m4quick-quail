# Enki Console Product Specification

## Product Overview

**Name:** Enki Console  
**Tagline:** "Your friendly interface for OpenClaw"  
**Category:** Web UI for OpenClaw  
**Target Market:** OpenClaw users, AI enthusiasts  
**Launch Date:** April 2026 (v1.0)

## Problem Statement

OpenClaw is powerful but requires terminal/TUI access. Users want:
- ChatGPT-style interface
- Easy access from any device
- Visual features (image upload, voice)
- No terminal required

## Solution

**Enki Console** = Beautiful web interface for OpenClaw

### Key Features

#### Current (v1.0)
- ✅ Chat interface with streaming responses
- ✅ Image upload and analysis
- ✅ Voice input (recording + transcription)
- ✅ Network monitoring dashboard
- ✅ ChickAi integration
- ✅ Mobile responsive
- ✅ Multi-device access

#### Planned (v1.5)
- [ ] Dark/light themes
- [ ] Customizable personas
- [ ] Plugin system
- [ ] Export conversations
- [ ] Keyboard shortcuts

## Technical

**Stack:** Flask + vanilla JS + Tailwind CSS
**Deployment:** Docker or direct install
**License:** MIT (open source)

## Positioning

**NOT:** Replacement for OpenClaw TUI
**BUT:** Alternative interface for different use cases

**Use TUI when:**
- Terminal power user
- SSH remote access
- Quick commands

**Use Enki Console when:**
- Visual interface preferred
- Image/voice features needed
- Mobile device access
- Sharing screen with others

## Distribution

**Primary:** GitHub (m4quick/enki-console)
**Marketing:** YouTube tutorials
**Integration:** Bundled with OpenClaw installer

## Branding

**Logo:** Enki mascot (friendly djinn/assistant)
**Colors:** Purple gradient (#667eea → #764ba2)
**Tone:** Helpful, friendly, not corporate
